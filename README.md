# 🧱 Tetris

A simple, colorful Tetris game for Android, designed kids.
Big buttons, bright blocks, slow falling pieces, and classic chiptune sounds.

## ✨ Features

- **Board Size** — 8 × 14 grid, so lines fill up quickly and clearing feels rewarding
- **Three big control buttons + fast-drop** at the bottom:
  - 🔄 **Rotate** (purple) — rotates the current piece clockwise 90°
  - ⏬ **Down** (orange) — hold to make the piece fall ~4× faster
  - ⬅️ **Left** (blue) / ➡️ **Right** (green) — move the piece sideways
  - All buttons use clear symbols instead of text
- **Line counter** in the top-right corner showing completed lines
- **Progressive speed** — pieces fall faster as you clear more lines (gentle ramp, still kid-friendly)
- **Pause** — tap anywhere outside the board to pause; tap again to continue
- **White & light-green theme** with chunky, brightly colored tetromino blocks
- **Classic game sounds** — ascending arpeggio on line clears, sad jingle on game over, soft ticks on moves
- **Tap to start / tap to restart** — no menus, no settings

## 📱 Requirements

- Android 5.0 (Lollipop, API 21) or later
- Phone or tablet in portrait mode

## 📥 Install

Download `tetrisgame.apk` from the [releases](../../releases) page (or grab it from
`app/build/outputs/apk/debug/tetrisgame.apk` after building), copy it to the device,
open it, and allow installation from unknown sources if prompted.

Or install via ADB:

```bash
adb install app/build/outputs/apk/debug/tetrisgame.apk
```

## 🛠️ Build from source

Requirements: JDK 17, Android SDK (platform 34, build-tools 34+). The Gradle wrapper
downloads everything else.

```bash
# point at your SDK (or set ANDROID_HOME)
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

./gradlew assembleDebug
# -> app/build/outputs/apk/debug/tetrisgame.apk
```

The debug build is automatically renamed to **`tetrisgame.apk`** by
`app/build.gradle`.

## 🕹️ How to play

1. Tap the board to start.
2. Pieces fall slowly from the top.
3. Use **LEFT** / **RIGHT** to slide the piece into place.
4. Use **ROTATE** to turn the piece.
5. Hold **DOWN** when you cannot wait any longer.
6. Fill a whole row to clear it — watch the **Lines** counter go up!
7. Tapping outside the board pauses the game; tap again to continue.

## 🔧 Tech notes

- Pure Java, no game engine — one custom `View` with `Canvas` drawing
- `Handler`-based gravity loop; drop interval scales with cleared lines
- `SoundPool` for low-latency effects (audio errors never crash the game)
- minSdk 21 · targetSdk 34 · Gradle 8.7 · AGP 8.1
